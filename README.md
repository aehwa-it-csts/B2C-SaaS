
# b2c-saas
# 한국수어 교육 웹앱 제작

## 1. 프로젝트 개요

- 프로젝트명: 한국수어 교육 웹앱
- 개발 인원: 4명
- 개발 목적: 한국수어 입문자를 위한 교육 웹페이지 제작
- 개발 환경: PC 웹 브라우저
- 개발 방법론: 애자일(Agile)
- 개발 목표: 30분 내 최소 기능 제품(MVP) 제작 및 출시

## 2. 요구사항

### 2.1 기능 요구사항

| ID | 기능 | 상세 내용 | 우선순위 |
|---|---|---|---|
| FR-01 | 수어 영상 학습 | 수어 교육 영상 1개와 의미 표시 | 필수 |
| FR-02 | 영상 제어 | 영상 재생 및 일시정지 | 필수 |

### 2.2 비기능 요구사항

| ID | 구분 | 요구사항 |
|---|---|---|
| NFR-01 | 사용성 | 누구나 쉽게 이용할 수 있는 화면 |
| NFR-02 | 접근성 | 음성 안내 없이 영상 학습 가능 |
| NFR-03 | 호환성 | Chrome, Edge 브라우저 지원 |

## 3. 설계

### 3.1 시스템 설계

- HTML 파일(index.html) 1개로 구성
- 수어 교육 영상 1개 제공
- 수어의 한국어 의미 표시
- HTML 기본 비디오 플레이어 사용
- 별도 서버 및 데이터베이스 없이 구현

### 3.2 화면 설계

1. 웹페이지 제목: 한국수어 배우기
2. 학습할 수어의 이름 표시
3. 수어 교육 영상 표시
4. 영상 재생 및 일시정지 기능 제공

### 3.3 사용자 이용 흐름

웹페이지 접속
→ 수어 교육 영상 확인
→ 영상 재생
→ 수어 학습
→ 반복 시청

## 4. 코딩

### 4.1 개발 방식

- LLM(ChatGPT)을 활용한 HTML 코드 작성
- index.html 파일 1개로 구현
- feature/1 브랜치에서 개발
- main 브랜치 직접 수정 금지

### 4.2 개발 순서

1. HTML 기본 웹페이지 생성
2. 수어 교육 영상 삽입
3. 수어 의미 표시
4. 영상 재생 기능 구현

## 5. 테스트

### 5.1 단위 테스트

- 수어 제목 및 의미 표시 확인
- 영상 재생 및 일시정지 확인

### 5.2 시스템 테스트

- 웹페이지 정상 실행 확인
- Chrome 브라우저에서 전체 기능 확인
- 영상 재생 오류 여부 확인

※ 테스트 완료 후 결과 기록

## 6. 출시

### 6.1 GitHub 관리

1. feature/1 브랜치에서 코드 작성
2. GitHub에 코드 커밋
3. Pull Request 생성
4. 검토 후 main 브랜치에 병합
5. GitHub Release 생성

### 6.2 버전 관리

- v0.1.0: 수어 교육 영상 1개 제공
- v0.2.0: 사용자 피드백 반영 및 기능 개선

### 6.3 고객 피드백

- 영상이 정상적으로 재생되는가?
- 화면 구성이 이해하기 쉬운가?
- 추가로 필요한 기능은 무엇인가?

피드백을 바탕으로 요구사항과 설계를 수정한다.

## 7. 향후 개발 계획

- 수어 교육 영상 추가
- 수어 단어별 학습 기능
- 웹캠 기반 수어 실습
- AI 수어 동작 인식
- 학습 퀴즈 및 평가 기능

## 8. 최종 목표

첫 번째 스프린트에서는 수어 교육 영상 1개를
재생할 수 있는 웹페이지를 제작한다.

이후 애자일 개발 방식으로 기능을 단계적으로
추가하여 AI 기반 한국수어 교육 웹앱으로 발전시킨다.
