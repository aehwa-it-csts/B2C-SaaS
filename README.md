# B2C SaaS – 한국수어 교육 웹앱 제작

## 1. 프로젝트 개요

- **프로젝트명:** 한국수어 교육 웹앱
- **개발 인원:** 4명
- **개발 목적:** 한국수어 입문자를 위한 교육 웹앱 제작
- **대상 사용자:** 한국수어 학습 입문자
- **개발 환경:** PC 웹 브라우저
- **개발 방법론:** 애자일(Agile)
- **개발 목표:** 30분 내 최소 기능 제품(MVP) 제작 및 출시

## 2. 요구사항 명세

### 2.1 기능 요구사항

| ID | 기능 | 상세 내용 | 우선순위 |
|---|---|---|---|
| FR-01 | 수어 영상 학습 | 수어 교육 영상 1개 및 한국어 의미 표시 | 필수 |
| FR-02 | 영상 제어 | 영상 재생 및 일시정지 | 필수 |
| FR-03 | 수어 동작 설명 | 수어 동작에 대한 단계별 설명 제공 | 높음 |

※ FR-03은 1차 고객 피드백을 통해 추가된 요구사항으로, v0.2.0에서 구현할 예정이다.

### 2.2 비기능 요구사항

| ID | 구분 | 요구사항 |
|---|---|---|
| NFR-01 | 사용성 | 누구나 쉽게 이용할 수 있는 화면 구성 |
| NFR-02 | 접근성 | 음성 안내 없이 영상 학습 가능 |
| NFR-03 | 호환성 | Chrome, Edge 브라우저 지원 |

## 3. 설계

### 3.1 시스템 설계

- HTML 파일(index.html) 1개로 구성
- 수어 교육 영상 및 한국어 의미 제공
- HTML 기본 비디오 플레이어 사용
- 별도 서버 및 데이터베이스 없이 구현

### 3.2 화면 설계

1. 웹페이지 제목: 한국수어 배우기
2. 학습할 수어의 이름 및 의미 표시
3. 수어 교육 영상 표시
4. 영상 재생 및 일시정지 기능 제공

### 3.3 사용자 이용 흐름

웹페이지 접속 → 수어 교육 영상 확인 → 영상 재생 → 수어 학습 → 반복 시청

## 4. 구현

### 4.1 개발 방식

- LLM(ChatGPT)을 활용한 HTML 코드 작성
- index.html 파일 1개로 구현
- feature/1 브랜치에서 개발
- main 브랜치 직접 수정 금지

### 4.2 개발 순서

1. HTML 기본 웹페이지 생성
2. 수어 교육 영상 삽입
3. 수어 이름 및 의미 표시
4. 영상 재생 및 제어 기능 구현

## 5. 테스트

## 8. 고객 피드백

### 8.1 긍정적 평가

- 수어 시범 영상 재생 및 다시 보기 가능

### 8.3 개선 방향

- 수어별 단계적 동작 설명 추가

- 한국수어사전을 기준으로 정확한 동작 설명 작성
