# b2c-saas
# 수어 교육 웹앱 제작
## 1. 프로젝트 개요

- 프로젝트명: 한국수어 AI 교육 웹앱
- 개발 인원: 4명
- 개발 목적: 한국수어 학습 및 AI 동작 인식 체험
- 주요 사용자: 한국수어 입문자
- 개발 환경: PC 웹 브라우저
- 개발 방법론: 애자일(Agile) 기반 반복적·점진적 개발
- 운영 방식: 무료 및 로컬 환경 중심
- 개발 원칙: 핵심 기능 우선 개발 및 단계적 개선

## 설계

### 3.1 시스템 설계

1. 프론트엔드
   - 수어 학습 화면 구성
   - 교육 영상 재생
   - 웹캠 실행 및 인식 결과 표시

2. 백엔드
   - 학습 데이터 관리
   - AI 인식 모듈 연동
   - 인식 결과 전달

3. AI 모듈
   - 손, 얼굴, 신체 특징점 추출
   - 수어 동작 분석 및 분류
   - 학습 대상 수어와 인식 결과 비교

4. 데이터
   - 수어 단어 및 의미
   - 수어 교육 영상
   - AI 학습 및 정답 데이터

### 3.2 UI/UX 설계

- 메인 화면: 수어 학습 시작 및 카테고리 선택
- 수어 목록: 학습할 수어 표현 선택
- 학습 화면: 교육 영상 및 의미 확인
- 실습 화면: 웹캠을 통한 수어 동작 연습
- 결과 화면: AI 인식 결과 확인 및 재도전

### 3.3 사용자 이용 흐름

메인 화면
→ 수어 선택
→ 교육 영상 학습
→ 웹캠 실습
→ AI 동작 인식
→ 결과 확인
→ 재도전 또는 다음 학습

### 3.4 AI 동작 인식 설계

1. 웹캠으로 수어 동작 촬영
2. MediaPipe를 이용한 특징점 추출
3. 추출한 데이터 전처리
4. AI 모델을 통한 수어 동작 분류
5. 학습 대상 수어와 결과 비교
6. 정답, 오답, 인식 불가 표시

초기에는 3~5개 수어 표현을 대상으로
AI 인식 기능을 검증하고,
이후 10~20개 표현으로 확대한다.

### 3.5 개발 기술 (예정)

- HTML, CSS, JavaScript: 웹 화면 개발
- Python: AI 모델 개발
- MediaPipe: 손, 얼굴, 신체 특징점 추출
- FastAPI: 웹앱과 AI 모델 연동
- JSON: 학습 데이터 관리
- GitHub: 코드 관리 및 협업

## 코딩
### 4.1 개발 방식

- LLM(ChatGPT 등)을 활용한 코드 작성
- 핵심 기능부터 단계적으로 구현
- 기능별 개발 및 테스트 진행
- GitHub feature/1 브랜치에서 작업
- main 브랜치 직접 수정 금지

### 4.2 개발 순서

1. 기본 웹페이지 제작
2. 수어 목록 및 영상 학습 기능 구현
3. 웹캠 연결 기능 구현
4. AI 수어 동작 인식 기능 구현
5. AI 인식 결과 화면 연동
6. 오류 수정 및 기능 개선

### 4.3 애자일 개발 계획

- Sprint 1: 요구사항 및 기본 설계
- Sprint 2: 수어 학습 기능 개발
- Sprint 3: 웹캠 및 특징점 추출
- Sprint 4: AI 수어 인식 기능 개발
- Sprint 5: 웹앱과 AI 연동
- Sprint 6: 테스트 및 기능 개선

각 스프린트마다 개발 결과를 확인하고
피드백을 반영하여 다음 단계로 진행한다.

## 7. 최종 개발 목표

한국수어 입문자가 교육 영상을 통해
수어를 학습하고 웹캠으로 직접 연습할 수 있는
AI 기반 수어교육 웹앱을 개발한다.

초기에는 최소 기능 제품(MVP)을 제작하고,
애자일 개발 방식을 통해 점진적으로
기능과 완성도를 개선한다.
